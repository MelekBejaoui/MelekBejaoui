## 🚀 Projects & Practical Experience

### 🌡️ ESP32 Environmental Monitoring

Developed and tested sensor readings using an ESP32 and environmental sensors, including the BME280. Integrated I2C communication and explored displaying temperature, pressure, and humidity data.

**Technologies:** ESP32-S3 · C++ · Arduino framework · BME280 · I2C

### 📊 IoT Monitoring Dashboard with Node-RED

Built a working IoT dashboard workflow to receive and visualize temperature and humidity data from a microcontroller. Also experimented with HTTP communication and connected-device control.

**Technologies:** ESP32 · Node-RED · HTTP · JSON · Adafruit IO

### 🏠 Mini Smart Home System — In Development

Developing a smart-home prototype combining microcontrollers, sensors, displays, a keypad, and actuators to explore home automation and embedded control.

**Planned and explored features:** Environmental monitoring, water/rain detection, keypad input, servo control, and buzzer alerts.

**Technologies:** ESP32-S3 · Arduino Uno · C++ · LCD · Keypad · Sensors · Servos

### 🔐 RFID Access Control — Experimentation

Explored an RFID access-control system using an MFRC522 reader, an ESP32, status LEDs, and MQTT communication.

**Technologies:** ESP32 · MFRC522 · C++ · MQTT
